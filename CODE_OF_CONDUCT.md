# Code of conduct

Be kind, assume good intent, and keep feedback about the work, not the person.

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). To report unacceptable behaviour, contact the maintainers privately through a [security advisory](https://github.com/devian-labs/betelgeuse/security/advisories/new).
