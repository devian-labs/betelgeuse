On Windows and Linux, use Ctrl for `⌘` and Alt for `⌥`.

## Anywhere

| Shortcut      | What it does              |
| ------------- | ------------------------- |
| `⌘K` or `⌘P`  | Search pages              |
| `⌘N`          | New page                  |
| `⌘\`          | Show or hide the sidebar  |
| `⌘[` and `⌘]` | Back and forward          |
| `⌘S`          | Commit changes to git now |
| `⌘,`          | Open Settings             |
| `Esc`         | Close the side peek       |

## Writing

| Shortcut         | What it does                                                |
| ---------------- | ----------------------------------------------------------- |
| `/`              | Open the block menu                                         |
| `[[`             | Link to a page                                              |
| `@`              | Mention a page or a date                                    |
| `⌘B`             | Bold                                                        |
| `⌘I`             | Italic                                                      |
| `⌘⇧S`            | Strikethrough                                               |
| `⌘E`             | Inline code                                                 |
| `⌘⇧H`            | Highlight in yellow                                         |
| `⌘Z` and `⌘⇧Z`   | Undo and redo                                               |
| `Tab` and `⇧Tab` | Indent and outdent a list item, or move between table cells |
| `⌘D`             | Duplicate the current block                                 |

## Turn into

| Shortcut | Block         |
| -------- | ------------- |
| `⌘⌥0`    | Text          |
| `⌘⌥1`    | Heading 1     |
| `⌘⌥2`    | Heading 2     |
| `⌘⌥3`    | Heading 3     |
| `⌘⌥4`    | To-do list    |
| `⌘⌥5`    | Bulleted list |
| `⌘⌥6`    | Numbered list |
| `⌘⌥7`    | Toggle list   |
| `⌘⌥8`    | Code          |

<details>
<summary>Markdown shortcuts</summary>

Type these at the start of a line:

- `#`, `##` or `###` and a space for a heading
- `-` and a space for a bulleted list
- `1.` and a space for a numbered list
- `[]` and a space for a to-do
- `>` and a space for a quote
- Three backticks and a space for a code block
- `---` for a divider

</details>

See [[Writing and blocks]] for what each block does, and [[Formatting and colours]] for colours.
